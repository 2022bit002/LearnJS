Math = Built in object that provide a collection of properties and methods
 	some famous methods of the Math object
 		Rounding Methods 
 			Math.round(x): Rounds a number to the nearest integer. Half values are rounded to the nearest integer in the direction of positive infinity (e.g., Math.round(4.5) 				is 5, Math.round(-4.5) is -4).
 			Math.ceil(x): Rounds a number up to the nearest integer (e.g., Math.ceil(4.2) is 5, Math.ceil(-4.8) is -4).
 			Math.floor(x): Rounds a number down to the nearest integer (e.g., Math.floor(4.9) is 4, Math.floor(-4.2) is -5).
 			Math.trunc(x): Returns the integer part of a number by removing any fractional digits (e.g., Math.trunc(4.9) is 4, Math.trunc(-4.2) is -4). 
 		Calculation Methods 
 			Math.abs(x): Returns the absolute ( positive) value of x (e.g., Math.abs(-5) is 5).
 			Math.pow(x, y): Returns the value of x to the power of y (i.e., \(x^{y}\)) (e.g., Math.pow(2, 3) is 8).
 			Math.sqrt(x): Returns the square root of x (e.g., Math.sqrt(25) is 5).
 			Math.min(...): Finds and returns the lowest value from a list of arguments (e.g., Math.min(0, 150, 30, 20) is -200).
 			Math.max(...): Finds and returns the highest value from a list of arguments (e.g., Math.max(0, 150, 30, 20) is 150).
 		Random Number Generation 
 			Math.random(): Returns a pseudo-random floating-point number between 0 (inclusive) and 1 (exclusive). This is commonly used in generating random integers within a 				specific range. 
 		Trigonometric and Logarithmic Methods 
 			Math.sin(x): Returns the sine of an angle x (in radians).
 			Math.cos(x): Returns the cosine of an angle x (in radians).Math.log(x): Returns the natural logarithm of x

String Methods

methods help to manipulate the string.

⦁	length property: While a property and not a method, length is crucial as it returns the number of characters in a string.

⦁	slice(start, end): Extracts a portion of a string and returns a new string. It accepts negative indices which count from the end of the string.

⦁	substring(start, end): Similar to slice(), it extracts characters between two specified indices. The main difference is that it treats negative values as 0.

⦁	replace(searchValue, newValue): Replaces a specified value or a regular expression match with a new value in a string. By default, it replaces only the first occurrence.

⦁	replaceAll(searchValue, newValue): Replaces all occurrences of a specified substring or regular expression match with a new value.

⦁	toUpperCase(): Converts all the characters in a string to uppercase letters and returns a new string.

⦁	toLowerCase(): Converts all the characters in a string to lowercase letters and returns a new string.

⦁	concat(string1, string2, ...): Joins two or more strings together to create a new, combined string. The + operator is often used as a simpler alternative.

⦁	trim(): Removes whitespace (spaces, tabs, newlines) from both ends (start and end) of a string.

⦁	split(separator): Divides a string into an array of substrings based on a specified separator.

⦁	indexOf(substring): Returns the index (position) of the first occurrence of a specified substring. It returns -1 if the substring is not found.

⦁	includes(substring): Checks if a string contains a specified substring and returns a boolean value (true or false).

⦁	startsWith(substring): Checks if a string begins with a specified substring and returns true or false.

⦁	endsWith(substring): Checks if a string ends with a specified substring and returns true or false.

⦁	charAt(index): Returns the character at a specified index in a string
